## Цель работы
Изучение механизмов работы с файловыми потоками ввода-вывода в языке C++, освоение правил выделения и освобождения динамической памяти для массивов объектов, а также приобретение навыков построчной обработки текстовых данных и манипулирования строками в оперативной памяти.

## Постановка задачи (Вариант 8)
Написать программу, считывающую символьный файл в динамическую память целиком построчно, формируя массив строк. Удалить из всех строк однострочные комментарии `//` непосредственно в памяти и записать очищенный результат в новый файл, имя которого вводится с клавиатуры. Программа разделена на три файла:
1. `my_lab10.h` — заголовочный файл с прототипами функций.
2. `my_lab10.cpp` — реализация функций работы с потоками и строками.
3. `main10.cpp` — точка входа и демонстрационный запуск.

## Алгоритм решения
1. **Первичное чтение входного файла:** подсчет точного количества строк в `code.txt` с помощью `std::getline`.
2. **Выделение памяти:** сброс флагов потока (`clear`), перемотка указателя (`seekg(0)`) и выделение массива строк через оператор `new std::string[count]`.
3. **Заполнение массива:** чтение содержимого файла в выделенные ячейки памяти.
4. **Фильтрация комментариев:** поиск `//` методом `find("//")` и усечение строки методом `substr(0, pos)`.
5. **Запись результата:** выгрузка измененных строк в целевой файл через `std::ofstream`.
6. **Очистка ресурсов:** освобождение массива оператором `delete[]`.

## Сборка и запуск

### Сборка через Makefile:
```bash

```

### Сборка напрямую через g++:
```bash
g++ -std=c++17 main10.cpp my_lab10.cpp -o lab10_app
./lab10_app
```
